One original one-line worst superpower for make.fun's "Worst Superpower" bounty, $2 in USDC. The entry is a single fixed line: mind-reading that only works on my own mind, out loud, during a job interview — a real power with zero usefulness and total embarrassment.

## Run it

```sh
python3 main.py
```

The program writes the superpower to `/output/entry.txt` (UTF-8, one line, no trailing newline) and prints it. It is deterministic: two runs write byte-identical output.
